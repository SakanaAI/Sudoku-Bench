# Sudoku-Bench

This project has been discontinued.

The source code and project materials are no longer available from this repository.

The `nikoli_100` dataset — 100 handmade standard Sudoku puzzles provided by [Nikoli](https://www.nikoli.co.jp/en/) — remains available at [huggingface.co/datasets/SakanaAI/sudoku-bench-nikoli](https://huggingface.co/datasets/SakanaAI/sudoku-bench-nikoli).
